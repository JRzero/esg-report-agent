# ESG Report Agent Engineering Constitution

1. **Evidence first**: factual claims must resolve to Fact and Evidence where applicable.
2. **Context is not truth**: OpenViking and LLM output are advisory context, not authoritative state.
3. **Service first**: all product capability must be exposed and testable without a UI.
4. **Controlled agent**: workflows, context scopes and tool permissions are explicit.
5. **Tenant safety**: tenant/project boundaries are enforced before data access.
6. **Immutable provenance**: original versions, anchors, revisions and audit records are append-only.
7. **Spec-driven delivery**: behavior changes require a spec/task change before implementation.
8. **Test the boundary**: cross-tenant/project access, fact confirmation and citation provenance are mandatory tests.
