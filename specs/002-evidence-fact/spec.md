# Evidence to Fact

## Intent
Upload immutable document versions, parse PDF/DOCX/XLSX anchors, bind OpenViking context, extract/confirm facts and detect conflicts.

## Acceptance criteria
- Document/version upload
- Object storage adapter
- PDF/DOCX/XLSX parsing
- Immutable anchors
- Context binding
- Fact candidates
- Fact confirmation/rejection
- Conflict groups
- Evidence trace API
